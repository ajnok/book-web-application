# 1. คุณสมบัติ CSS พื้นฐานในการจัดรูปแบบอิลิเมนต์ (Box Model)

อ้างอิงจากหนังสือ หน้า 221-227

| ตัวอย่างที่ (หนังสือ) | หน้า | คำอธิบาย | ไฟล์ |
|---|---|---|---|
| 1 | 223 | คุณสมบัติในการควบคุมขนาดของอิลิเมนต์ (width, height, min-width, max-width) | example-01-size-properties.css, example-01-size-properties.html |
| 2 | 224 | คุณสมบัติในการจัดการเส้นขอบของอิลิเมนต์ (border-top/right/bottom/left และ border แบบย่อ) | example-02-border-properties.css, example-02-border-properties.html |
| 3 | 226 | คุณสมบัติในการจัดการระยะห่างภายในของอิลิเมนต์ (padding) | example-03-padding-properties.css, example-03-padding-properties.html |
| 4 | 227 | คุณสมบัติในการจัดการระยะห่างภายนอกของอิลิเมนต์ (margin) | example-04-margin-properties.css, example-04-margin-properties.html |

หมายเหตุ: ในหนังสือแต่ละตัวอย่างแสดงเป็นตารางสองคอลัมน์ (CSS และ HTML) คู่กัน จึงแยกบันทึกเป็น 2 ไฟล์ต่อหนึ่งตัวอย่างตามเนื้อหาที่ปรากฏจริง ตัวอย่างที่ 1 ในหนังสือ (หน้า 223) มีตัวเลือก `.box2` ที่เขียนเครื่องหมาย `{` ไว้คนละบรรทัดกับชื่อตัวเลือก (ต่างจาก `.box1` ที่เขียนไว้บรรทัดเดียวกัน) จึงคงรูปแบบการจัดบรรทัดไว้ตามต้นฉบับ
