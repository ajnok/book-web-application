# 4. สีและหน่วยวัด

อ้างอิงจากหนังสือ หน้า 212-218

| ตัวอย่างที่ (หนังสือ) | หน้า | คำอธิบาย | ไฟล์ |
|---|---|---|---|
| 15 | 212-213 | การกำหนดค่าสีโดยใช้ชื่อสี (Color Name) | example-15-color-name.css |
| 16 | 213 | การกำหนดค่าสีโดยใช้ฟังก์ชัน rgb() | example-16-color-rgb.css |
| 17 | 214 | การกำหนดค่าสีโดยใช้ฟังก์ชัน rgba() | example-17-color-rgba.css |
| 18 | 215 | การกำหนดค่าสีโดยใช้เลขฐานสิบหก (Hexadecimal Color Code) | example-18-color-hex.css |
| 19 | 216 | การกำหนดขนาดด้วยหน่วยวัดสัมบูรณ์ px | example-19-unit-px.css, example-19-unit-px.html |
| 20 | 217 | การกำหนดขนาดด้วยหน่วยวัดสัมพัทธ์ vw | example-20-unit-vw.css, example-20-unit-vw.html |

หมายเหตุ:

- ตัวอย่างที่ 15 ในหนังสือ (หน้า 212-213) เขียนตัวเลือก h1 และเครื่องหมาย { ไว้คนละบรรทัดกัน (ต่างจากตัวเลือก a ที่เขียน { ต่อท้ายบรรทัดเดียวกัน) จึงคงรูปแบบการจัดบรรทัดไว้ตามต้นฉบับโดยไม่ปรับให้สม่ำเสมอกัน
- ตัวอย่างที่ 19 และ 20 ในหนังสือแสดงเป็นตารางสองคอลัมน์ (CSS และ HTML) คู่กัน จึงแยกบันทึกเป็น 2 ไฟล์ต่อหนึ่งตัวอย่างตามเนื้อหาที่ปรากฏจริง
