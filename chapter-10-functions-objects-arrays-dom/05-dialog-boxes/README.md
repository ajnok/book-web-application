# 4.2 กล่องโต้ตอบ

อ้างอิงจากหนังสือ หน้า 355-359

| ตัวอย่างที่ (หนังสือ) | หน้า | คำอธิบาย | ไฟล์ |
|---|---|---|---|
| 32 | 355 | ฟังก์ชัน alert() | example-32-alert.html |
| 33 | 356-357 | ฟังก์ชัน prompt() (HTML + dialog.js) | example-33-prompt.html, dialog-33.js |
| 34 | 357-358 | ฟังก์ชัน confirm() (HTML + dialog.js) | example-34-confirm.html, dialog-34.js |

หมายเหตุ (คงตามต้นฉบับหนังสือโดยไม่แก้ไข):
- ตัวอย่างที่ 33 และ 34: หนังสือตั้งชื่อไฟล์ JavaScript ภายนอกว่า `dialog.js` ซ้ำกันทั้งสองตัวอย่างทั้งที่เนื้อหาโค้ดแตกต่างกัน เนื่องจากในโครงสร้าง Repository นี้ทั้งสองตัวอย่างต้องอยู่ในโฟลเดอร์เดียวกัน จึงตั้งชื่อไฟล์เป็น `dialog-33.js` และ `dialog-34.js` เพื่อไม่ให้ไฟล์ทับกัน โดยเนื้อหาโค้ดภายในคงไว้ตามต้นฉบับทุกประการ
- ตัวอย่างที่ 33 และ 34: บรรทัด `<script  src="dialog.js">` มีการเว้นวรรคซ้ำหลัง `<script` และไม่มีแท็กปิด `</script>` ตามที่ปรากฏในต้นฉบับหนังสือ (หน้า 356, 358) จึงคงไว้ตามเดิม
- ตัวอย่างที่ 34 (dialog-34.js): บรรทัด `console.log("ยกเลิกการลบข้อมูล");` ภายในบล็อก else มีการเยื้องบรรทัดน้อยกว่าบรรทัดอื่น ตามที่ปรากฏในต้นฉบับหนังสือ (หน้า 358) จึงคงไว้ตามเดิม
