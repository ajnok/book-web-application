# 1. การรับค่าจากฟอร์ม

อ้างอิงจากหนังสือ หน้า 424-432

| ตัวอย่างที่ (หนังสือ) | หน้า | คำอธิบาย | ไฟล์ |
|---|---|---|---|
| 1 | 424-425 | การรับข้อมูลด้วยตัวแปร $_GET (HTML + search.php) | example-01-get.html, search.php |
| 2 | 425-426 | การรับข้อมูลด้วยตัวแปร $_POST (HTML + login.php) | example-02-post.html, login.php |
| 3 | 427 | ฟังก์ชัน empty() | example-03-empty.php |
| 4 | 428 | ฟังก์ชัน isset() | example-04-isset.php |
| 5 | 428 | ฟังก์ชัน strlen() | example-05-strlen.php |

| 7 | 430 | ฟังก์ชัน trim() | example-07-trim.php |

หมายเหตุ (คงตามต้นฉบับหนังสือโดยไม่แก้ไข เว้นแต่จุดที่ระบุไว้ว่า "แก้ไขแล้ว"):
- **ตัวอย่างที่ 6 (แก้ไขแล้ว)**: ต้นฉบับหนังสือ (หน้า 429) พิมพ์บรรทัดที่ 2 เป็น `if (Ifilter_var($email, FILTER_VALIDATE_EMAIL)) {` โดยมีอักขระ "I" นำหน้าคำว่า filter_var แทนที่จะเป็นเครื่องหมาย `!` ซึ่งทำให้เกิด Fatal error: Call to undefined function เมื่อรันจริง (ตามคำอธิบายเนื้อหาในหนังสือสื่อว่าเป็นการตรวจสอบค่าที่ *ไม่* ผ่านรูปแบบอีเมล) ตามคำขอของผู้เขียนจึงแก้ไขไฟล์ `example-06-filter-var-validate.php` โดยเปลี่ยนเป็น `if (!filter_var($email, FILTER_VALIDATE_EMAIL)) {` เพื่อให้โค้ดสามารถรันได้ถูกต้อง (เป็นข้อยกเว้นในหัวข้อนี้ที่มีการแก้ไขโค้ดจากต้นฉบับหนังสือ)
- **ตัวอย่างที่ 10 (แก้ไขแล้ว)**: ต้นฉบับหนังสือ (หน้า 432) พิมพ์บรรทัดที่ 1 และ 3 กำหนดค่าตัวแปร `$email = "web<script>@example.com";` ซ้ำกันสองครั้ง และบรรทัดที่ 6 อ้างอิงตัวแปร `$comment` ซึ่งไม่ได้ถูกประกาศไว้ในโค้ดตัวอย่างนี้ (เป็นตัวแปรที่ปรากฏในตัวอย่างที่ 9 ก่อนหน้า) ทำให้เกิด Warning: Undefined variable เมื่อรันจริง ตามคำขอของผู้เขียนจึงแก้ไขไฟล์ `example-10-filter-var-sanitize.php` โดยเปลี่ยนบรรทัดที่ 3 จากการกำหนดค่าซ้ำให้เป็น `$comment = "<script>alert('XSS');</script>";` (ค่าเดียวกับที่ประกาศไว้ในตัวอย่างที่ 9) เพื่อให้ตัวแปร `$comment` มีค่าและโค้ดสามารถรันได้ถูกต้อง (เป็นข้อยกเว้นในหัวข้อนี้ที่มีการแก้ไขโค้ดจากต้นฉบับหนังสือ)
