# 4.1 รูปแบบการใช้งานภาษา JavaScript ในเอกสารเว็บ

อ้างอิงจากหนังสือ หน้า 349-354

| ตัวอย่างที่ (หนังสือ) | หน้า | คำอธิบาย | ไฟล์ |
|---|---|---|---|
| 30 | 351 | การใช้ภาษา JavaScript แบบแทรกในแท็ก (Inline JavaScript) | example-30-inline-javascript.html |
| 31 | 352-353 | การใช้ภาษา JavaScript แบบภายใน (Internal JavaScript) | example-31-internal-javascript.html |

หมายเหตุ: หัวข้อ 4.1.3 การใช้ภาษา JavaScript แบบภายนอก (External JavaScript หน้า 354) มีเพียงคำอธิบายขั้นตอนและกล่องรูปแบบ (`<script src="ชื่อไฟล์.js"></script>`) โดยไม่มีตัวอย่างที่มีเลขกำกับ (ตัวอย่างที่ ...) จึงไม่ได้สร้างไฟล์แยกสำหรับหัวข้อนี้ (แนวคิดการใช้ไฟล์ JavaScript ภายนอกปรากฏจริงในตัวอย่างถัดไปของบทนี้ เช่น ตัวอย่างที่ 33 เป็นต้นไป)

ตัวอย่างที่ 31: บรรทัด `<p  id="content">เนื้อหาของอิลิเมนต์ p</p>` มีการเว้นวรรคซ้ำ (double space) ระหว่าง `<p` และ `id="content"` ตามต้นฉบับหนังสือ (หน้า 352) จึงคงไว้ตามเดิมโดยไม่แก้ไข
