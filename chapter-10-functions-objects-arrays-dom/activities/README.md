# กิจกรรมท้ายบท - บทที่ 10: การจัดการข้อมูลและอิลิเมนต์ด้วย JavaScript

อ้างอิงจากหนังสือ หน้า 374

6.1 จงอธิบายบทบาทของฟังก์ชันในภาษา JavaScript พร้อมทั้งแสดงตัวอย่างการประกาศฟังก์ชันทั้ง 3 รูปแบบที่ศึกษาในบทนี้ ได้แก่ Function Declaration, Function Expression และ Arrow Function พร้อมระบุความแตกต่างระหว่างรูปแบบเหล่านั้น

6.2 พารามิเตอร์และค่าที่ส่งกลับจากฟังก์ชันมีความสำคัญอย่างไรในการพัฒนาเว็บแอปพลิเคชัน? จงอธิบายและแสดงตัวอย่างฟังก์ชันที่รับพารามิเตอร์และส่งค่ากลับ

6.3 อธิบายความแตกต่างระหว่างออบเจกต์กับอาร์เรย์ในภาษา JavaScript ในด้านโครงสร้างการจัดเก็บข้อมูลและวิธีการเข้าถึง พร้อมยกตัวอย่างการประกาศและเข้าถึงข้อมูลในแต่ละแบบ

6.4 DOM (Document Object Model) มีความสำคัญอย่างไรต่อการพัฒนาเว็บแอปพลิเคชันแบบโต้ตอบ? จงอธิบายกลไกที่ JavaScript ใช้ค้นหาและปรับเปลี่ยนอิลิเมนต์ผ่าน DOM พอสังเขป

6.5 เหตุการณ์ (Event) ใน JavaScript หมายถึงอะไร? จงยกตัวอย่างเหตุการณ์ที่พบบ่อยในการพัฒนาเว็บแอปพลิเคชัน พร้อมแสดงรูปแบบการเขียน Event Handler ที่ใช้กับอิลิเมนต์ของหน้าเว็บอย่างน้อย 2 รูปแบบ

6.6 จงเขียนเอกสารเว็บที่ประกอบด้วยฟอร์มรับข้อมูลชื่อและอายุ โดยมีข้อกำหนดดังนี้

- 6.6.1 เมื่อผู้ใช้กดปุ่มส่ง ให้ฟังก์ชัน JavaScript ตรวจสอบว่ากรอกข้อมูลครบหรือไม่ หากไม่ครบให้แสดงข้อความแจ้งเตือนใน DOM โดยไม่ใช้ alert()
- 6.6.2 หากข้อมูลครบ ให้แสดงข้อความต้อนรับในรูปแบบ "สวัสดีคุณ [ชื่อ] อายุ [อายุ] ปี" ในพื้นที่แสดงผลบนหน้าเว็บ โดยให้ปรากฏอยู่ท้ายฟอร์ม
- 6.6.3 บันทึกไฟล์เป็น form-validate.html แล้วทดสอบในเว็บเบราว์เซอร์
