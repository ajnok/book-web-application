# 2. การทำงานร่วมกับฐานข้อมูล

อ้างอิงจากหนังสือ หน้า 436-443

| รายการ | หน้า | คำอธิบาย | ไฟล์ |
|---|---|---|---|
| - | 436-437 | ไฟล์ SQL สำหรับสร้างฐานข้อมูล blog_system และตาราง users, posts | blogsystem.sql |
| ตัวอย่างที่ 11 | 438 | การสร้าง PDO Object | example-11-create-pdo-object.php |
| ตัวอย่างที่ 12 | 439 | การใช้โครงสร้าง try...catch ร่วมกับ PDO | example-12-try-catch.php |
| ตัวอย่างที่ 13 | 440 | ฟังก์ชัน prepare() | example-13-prepare.php |
| ตัวอย่างที่ 14 | 441 | ฟังก์ชัน execute() | example-14-execute.php |
| ตัวอย่างที่ 15 | 442 | ฟังก์ชัน fetch() | example-15-fetch.php |
| ตัวอย่างที่ 16 | 442-443 | ฟังก์ชัน fetchAll() | example-16-fetchall.php |
| ตัวอย่างที่ 17 | 443 | ฟังก์ชัน rowCount() | example-17-rowcount.php |

หมายเหตุ: ไฟล์ blogsystem.sql เป็นรหัสคำสั่งที่ปรากฏในหนังสือ (หน้า 436-437) ภายใต้หัวข้อ "2.3.3 จัดเตรียมฐานข้อมูล" โดยไม่มีเลขกำกับแบบ "ตัวอย่างที่ ..." จึงบันทึกชื่อไฟล์ตามที่หนังสือระบุไว้ในตาราง "ไฟล์ SQL" คือ `blogsystem.sql`

หมายเหตุ: กล่องรูปแบบ (รูปแบบ) ของหัวข้อ 2.4.6 ฟังก์ชัน fetchAll() (หน้า 442) พิมพ์เป็น `$pdoStatement->fetch(โหมดการคืนค่า);` ซึ่งเป็นชื่อเมธอดที่ไม่ตรงกับหัวข้อ (ควรเป็น fetchAll()) แต่ตัวอย่างที่ 16 ในเนื้อหาใช้เมธอด fetchAll() ถูกต้อง จึงคงข้อสังเกตนี้ไว้เป็นหมายเหตุโดยไม่มีการแก้ไขโค้ดตัวอย่าง
