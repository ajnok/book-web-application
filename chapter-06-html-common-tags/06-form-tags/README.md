# 6. แท็กสำหรับการสร้างฟอร์มรับข้อมูล

อ้างอิงจากหนังสือ หน้า 167-173

| ตัวอย่างที่ (หนังสือ) | หน้า | คำอธิบาย | ไฟล์ |
|---|---|---|---|
| 15 | 171 | การสร้างช่องกรอกข้อมูลแบบเลือกรายการเดียว (Radio Button) | example-15-radio-button.html |
| 16 | 171 | การสร้างช่องกรอกข้อมูลแบบเลือกหลายรายการ (Checkbox) | example-16-checkbox.html |
| 17 | 172 | การสร้างช่องกรอกข้อมูลแบบเลือกจากรายการที่กำหนดไว้ (Dropdown List) ด้วยแท็ก select และ option | example-17-select-dropdown.html |

หมายเหตุ:

- หัวข้อนี้ในหนังสือยังมีรูปแบบ (ไม่ใช่ตัวอย่างที่มีเลขกำกับ) ของแท็กสำหรับรับข้อความสั้น รับรหัสผ่าน รับตัวเลข รับอีเมล รับวันที่ ปุ่มส่งข้อมูล (submit) และปุ่มรีเซ็ตข้อมูล (reset) ซึ่งแสดงเพียงรูปแบบทั่วไปโดยไม่มีตัวอย่างที่มีเลขกำกับ (ตัวอย่างที่) กำกับไว้ จึงไม่ได้สร้างไฟล์แยกสำหรับส่วนนี้ตามนโยบายที่ยึดเฉพาะโค้ดตัวอย่างที่มีเลขกำกับในหนังสือ
- ตัวอย่างที่ 16 บรรทัดที่ 1 มีค่าแอตทริบิวต์ `name="skill_1 "` ซึ่งมีช่องว่างอยู่ก่อนเครื่องหมายอัญประกาศปิด ตามต้นฉบับในหนังสือ (หน้า 171) จึงคงไว้ตามเดิมโดยไม่แก้ไข
