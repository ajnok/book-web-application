# 2. แท็กสำหรับการสร้างลิงก์

อ้างอิงจากหนังสือ หน้า 148-152

| ตัวอย่างที่ (หนังสือ) | หน้า | คำอธิบาย | ไฟล์ |
|---|---|---|---|
| 2 | 149-150 | การเชื่อมโยงไปยังตำแหน่งเฉพาะภายในเอกสารเดียวกันด้วย href="#id" (ตัวอย่างบางส่วนจากบรรทัดที่ 15 และ 90 ของเอกสารเดียวกัน) | example-02-a-internal-anchor.html |
| 3 | 150 | การเชื่อมโยงไปยัง URL ภายนอกที่กำหนด | example-03-a-external-url.html |
| 4 | 150-151 | การเชื่อมโยงไปยังเอกสารเว็บที่อยู่ในเครื่องผู้ให้บริการเว็บเดียวกัน (Relative Path) | example-04-a-relative-path.html |
| 5 | 151 | การเชื่อมโยงเพื่อส่งอีเมลด้วย mailto: | example-05-a-mailto.html |

หมายเหตุ:

- ตัวอย่างที่ 2 ในหนังสือแสดงเพียงสองบรรทัดที่ไม่ต่อเนื่องกัน (บรรทัดที่ 15 และ 90) จากเอกสารเดียวกันเพื่อประกอบคำอธิบาย จึงคงไว้ตามเดิมโดยไม่เติมเนื้อหาส่วนที่ขาดหาย
- ตัวอย่างที่ 7 มีช่องว่างสองช่องระหว่าง `"webapp.pdf"` กับ `download` ตามต้นฉบับในหนังสือ (หน้า 152) จึงคงไว้ตามเดิมโดยไม่แก้ไข
