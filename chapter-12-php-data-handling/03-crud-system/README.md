# 3. ระบบ CRUD

อ้างอิงจากหนังสือ หน้า 447-473

ระบบ CRUD ตัวอย่างในหนังสือ (การจัดการข้อมูลผู้ใช้ในตาราง users ของฐานข้อมูล blog_system) ประกอบด้วยไฟล์หลัก 8 ไฟล์ ตามที่หนังสือระบุไว้ในหัวข้อ 3.3.1-3.5.6 โดยแต่ละไฟล์อ้างอิงตามหน้าดังนี้:

| ไฟล์ | หน้า | บทบาทในระบบ CRUD |
|---|---|---|
| config.php | 448-449 | ไฟล์การตั้งค่าการเชื่อมต่อฐานข้อมูล (สร้าง PDO Object ส่วนกลาง) |
| test_connection.php | 449-450 | ไฟล์ทดสอบการเชื่อมต่อฐานข้อมูล |
| index.php | 451-453 | หน้าแสดงรายการข้อมูลทั้งหมด (Read) |
| add.php | 455-456 | หน้าฟอร์มสำหรับเพิ่มข้อมูลใหม่ (Create) |
| add_process.php | 457-459 | ไฟล์ประมวลผลการเพิ่มข้อมูล (Create) |
| edit.php | 461-465 | หน้าฟอร์มสำหรับแก้ไขข้อมูล (Update) |
| edit_process.php | 466-469 | ไฟล์ประมวลผลการแก้ไขข้อมูล (Update) |
| delete_process.php | 471-472 | ไฟล์ประมวลผลการลบข้อมูล (Delete) |

หมายเหตุ (คงตามต้นฉบับหนังสือโดยไม่แก้ไข เว้นแต่จุดที่ระบุไว้ว่า "แก้ไขแล้ว"):
- **ไฟล์ edit.php (แก้ไขแล้ว)**: ต้นฉบับหนังสือ (หน้า 461) พิมพ์บรรทัดที่ 4 เป็น `if (!isset($_GET['id']) || !lis_numeric($_GET['id'])) {` โดยมีการพิมพ์ชื่อฟังก์ชันผิดเป็น `lis_numeric` (มีตัวอักษร "l" เกินมาก่อนคำว่า is_numeric) ซึ่งฟังก์ชันดังกล่าวไม่มีอยู่จริงในภาษา PHP และทำให้เกิด Fatal error: Call to undefined function เมื่อเรียกใช้งานจริง (ทั้งนี้ไฟล์ delete_process.php ในหน้า 471 ที่ใช้ตรรกะลักษณะเดียวกัน สะกดคำว่า `is_numeric` ถูกต้อง) ตามคำขอของผู้เขียนจึงแก้ไขไฟล์ `edit.php` โดยเปลี่ยนเป็น `if (!isset($_GET['id']) || !is_numeric($_GET['id'])) {` เพื่อให้โค้ดสามารถรันได้ถูกต้อง (เป็นข้อยกเว้นในไฟล์นี้ที่มีการแก้ไขโค้ดจากต้นฉบับหนังสือ)
- ไฟล์ index.php: บรรทัด `th,td { border: 1px solid #ddd; padding: 8px; text-align: left; }` มีการเว้นวรรคกว้างระหว่าง `#ddd;` กับ `padding` ตามการจัดวางในต้นฉบับหนังสือ (หน้า 451)
- ทุกไฟล์ในโฟลเดอร์นี้อ้างอิงไฟล์ config.php ในโฟลเดอร์เดียวกันผ่านคำสั่ง `require_once 'config.php';` ตามโครงสร้างที่หนังสือออกแบบไว้ (ไฟล์ config.php ในหนังสือระบุตำแหน่งเป็น c:\webapp\source\config.php ซึ่งเป็นตัวอย่างพาธของผู้เขียน)
- ไฟล์ SQL สำหรับสร้างฐานข้อมูลและตาราง (blogsystem.sql) อยู่ในโฟลเดอร์ 02-database-connection ของบทนี้ เนื่องจากเนื้อหาส่วนนี้ปรากฏก่อนหัวข้อระบบ CRUD ในหนังสือ
