# กิจกรรมท้ายบท - บทที่ 7: ภาษา CSS

อ้างอิงจากหนังสือ หน้า 218-220

6.1 จงอธิบายความหมายและบทบาทของ CSS ในการพัฒนาเว็บแอปพลิเคชัน พร้อมอธิบายว่าแนวทาง CSS Modules ที่กำหนดโดย W3C แตกต่างจากการกำหนดเวอร์ชันแบบเดิม (CSS1, CSS2) อย่างไร?

6.2 โครงสร้างของคำสั่ง CSS ประกอบด้วยส่วนประกอบใดบ้าง? อธิบายความหมายและหน้าที่ของแต่ละส่วนพอสังเขป

6.3 การแทรกคำสั่ง CSS สามารถทำได้กี่วิธี แต่ละวิธีมีลักษณะอย่างไร? และเหมาะสมกับการใช้งานในกรณีใด? พร้อมสรุปข้อดีความสำคัญของแต่ละวิธีที่มีการกำหนดคุณสมบัติซ้ำซ้อนกัน

6.4 อธิบายหน้าที่ของ Selector ชนิดต่าง ๆ ดังต่อไปนี้ พร้อมยกตัวอย่างการใช้งานร่วมกับอิลิเมนต์ของเอกสารเว็บ

- 6.4.1 Type Selector
- 6.4.2 Class Selector
- 6.4.3 ID Selector
- 6.4.4 Descendant Selector
- 6.4.5 Pseudo-class Selector

6.5 หน่วยวัดใน CSS มีแบบใดบ้าง? จงเปรียบเทียบความแตกต่างระหว่างหน่วยวัดแบบสัมบูรณ์และสัมพัทธ์ และหน่วยใดที่เหมาะสมสำหรับการพัฒนาเว็บที่ตอบสนองต่ออุปกรณ์ (Responsive Design)

6.6 การกำหนดค่าสีใน CSS มีรูปแบบใดบ้าง? จงอธิบายความแตกต่างระหว่างการใช้ชื่อสี, รหัส Hex และรูปแบบ RGB พร้อมยกตัวอย่างประกอบ

6.7 จากโครงหน้าเว็บที่สร้างขึ้นจากบทก่อนหน้า จงสร้างไฟล์ CSS ภายนอกชื่อ style.css และเชื่อมโยงกับไฟล์ HTML เพื่อกำหนดลักษณะการแสดงผลของหน้าเว็บให้ใกล้เคียงกับตัวอย่างดังภาพที่ 7.3 โดยมุ่งเน้นการใช้ Selector การกำหนดสี หน่วยวัด และ Pseudo-class Selector ตามที่ศึกษาในบทนี้ โดยมีข้อกำหนดดังนี้

- 6.7.1 กำหนดส่วนหัวของหน้าเว็บ (header) ให้มี id เป็น site-header และใช้ ID Selector เพื่อกำหนดสีพื้นหลังเป็นสีฟ้าอ่อน ส่วนหัวเรื่องหลัก (h1) ให้ใช้ Type Selector เพื่อกำหนดสีข้อความเป็นสีน้ำเงินเข้ม โดยกำหนดสีด้วยรหัส Hex
- 6.7.2 กำหนดส่วนนำทาง (nav) ให้มี class เป็น main-menu และใช้ Class Selector เพื่อกำหนดสีพื้นหลังเป็นสีเทาอ่อน พร้อมกำหนด padding เป็น 5px และใช้ Pseudo-class Selector กับลิงก์ทุกลิงก์ เพื่อเปลี่ยนสีข้อความหรือสีพื้นหลังเมื่อผู้ใช้เลื่อนตัวชี้เมาส์ไปวางบนลิงก์
- 6.7.3 กำหนดพื้นที่ส่วนเนื้อหาหลัก (main) ให้มี class เป็น content และส่วนด้านข้าง (aside) ให้มี id เป็น sidebar จากนั้นใช้ Class Selector และ ID Selector เพื่อกำหนดสีพื้นหลังลักษณะดังภาพ พร้อมกำหนด padding ของทั้งสองส่วนเป็น 5px
- 6.7.4 กำหนดตารางให้มีความกว้าง 100% และกำหนด padding ของอิลิเมนต์ th และ td เป็น 5px โดยให้หัวตารางมีสีพื้นหลังเป็นสีเทาอ่อนและสีข้อความเป็นสีดำ
- 6.7.5 ใช้ Pseudo-class Selector เช่น tr:nth-child(even) หรือ tr:nth-child(odd) เพื่อกำหนดสีพื้นหลังของแถวข้อมูลในตารางแบบสลับแถว โดยกำหนดสีด้วยรหัส Hex หรือรูปแบบ RGB
- 6.7.6 กำหนดส่วนท้ายของหน้าเว็บ (footer) ให้มี class เป็น footer และใช้ Class Selector เพื่อกำหนดสีพื้นหลังเป็นสีเข้ม สีข้อความเป็นสีขาว และกำหนด padding เป็น 5px
- 6.7.7 ทดลองเปลี่ยนความกว้างของตารางเป็น 50% จากนั้นปรับลดและขยายขนาดของเว็บเบราว์เซอร์แล้วสังเกตผลการเปลี่ยนแปลงของตาราง
