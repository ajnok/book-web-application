# 6.1 ฟังก์ชัน

อ้างอิงจากหนังสือ หน้า 405-409

| ตัวอย่างที่ (หนังสือ) | หน้า | คำอธิบาย | ไฟล์ |
|---|---|---|---|
| 13 | 406 | การสร้างฟังก์ชัน (Function Declaration) | example-13-declaring-functions.php |
| 14 | 406-407 | การเรียกใช้ฟังก์ชัน | example-14-calling-functions.php |
| 15 | 408 | การกำหนดค่าเริ่มต้นให้พารามิเตอร์ | example-15-default-parameter.php |
| 16 | 408 | การส่งค่าให้พารามิเตอร์แบบระบุชื่อ (Named Arguments) | example-16-named-arguments.php |
| 17 | 409 | การส่งค่ากลับจากฟังก์ชันด้วย return | example-17-return-value.php |

หมายเหตุ (คงตามต้นฉบับหนังสือโดยไม่แก้ไข เว้นแต่จุดที่ระบุไว้ว่า "แก้ไขแล้ว"):
- ตัวอย่างที่ 16: ในหนังสือแสดงเป็นบรรทัดคำสั่งเดี่ยว (การเรียกใช้ฟังก์ชัน greet() ที่ประกาศไว้ในตัวอย่างที่ 15 โดยส่งค่าด้วยการระบุชื่อพารามิเตอร์) จึงบันทึกเป็นไฟล์แยกตามที่ปรากฏโดยไม่มีแท็ก `<?php` และ `?>` ครอบ
- **ตัวอย่างที่ 17 (แก้ไขแล้ว)**: ต้นฉบับหนังสือ (หน้า 409) พิมพ์บรรทัดที่ 3 เป็น `$currentYear = 2568` โดยไม่มีเครื่องหมายอัฒภาค (;) ปิดท้าย ซึ่งทำให้ PHP เกิด Parse error หากนำไปรันจริง ตามคำขอของผู้เขียนจึงแก้ไขไฟล์ `example-17-return-value.php` โดยเติมเครื่องหมายอัฒภาคให้เป็น `$currentYear = 2568;` เพื่อให้โค้ดสามารถรันได้ถูกต้อง (เป็นข้อยกเว้นเดียวในหัวข้อนี้ที่มีการแก้ไขโค้ดจากต้นฉบับหนังสือ)
