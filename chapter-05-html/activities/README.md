# กิจกรรมท้ายบท - บทที่ 5: ภาษา HTML

อ้างอิงจากหนังสือ หน้า 146

7.1 จงอธิบายความหมายและบทบาทของภาษา HTML ในการพัฒนาเว็บแอปพลิเคชัน

7.2 แท็กและแอตทริบิวต์ในภาษา HTML คืออะไร? มีความแตกต่างกันอย่างไร และอิลิเมนต์เกิดขึ้นได้อย่างไร? จงอธิบายพร้อมยกตัวอย่างประกอบ

7.3 ค่าเริ่มต้นการแสดงผลของอิลิเมนต์แบ่งได้เป็น 2 ประเภท มีอะไรบ้าง? พร้อมทั้งอธิบายลักษณะการแสดงผลในแต่ละประเภทและยกตัวอย่างแท็กในแต่ละประเภท

7.4 จงเขียนโครงสร้างของภาษา HTML ที่ใช้ในการสร้างเอกสารเว็บตามมาตรฐาน HTML Living Standard ให้ถูกต้อง โดยมีรายละเอียดดังนี้

- 7.4.1 กำหนดรหัสอักขระที่ใช้ในเว็บเป็น UTF-8 และตั้งค่าหน้าต่างมุมมองให้มีความกว้างเท่ากับอุปกรณ์ (Device Width) และกำหนดระดับการขยายเริ่มต้น (Initial scale) เป็น 1.0
- 7.4.2 กำหนดข้อมูลสนับสนุนเครื่องมือค้นหา ดังนี้
  - กำหนดชื่อเว็บแอปพลิเคชัน (Application Name) เป็น ระบบถามตอบ
  - ระบุคำสำคัญที่เกี่ยวข้องกับเนื้อหาในหน้าเว็บ (Keywords) จำนวน 3 คำ คือ Web App, ระบบเว็บ และการเขียนโปรแกรมบนเว็บ
- 7.4.3 กำหนดชื่อเรื่องของเว็บ (Page Title) เป็น Web Application

7.5 จากโครงสร้างภาษา HTML ในข้อ 7.4 จงวาดภาพ DOM Tree เพื่อแสดงความสัมพันธ์ของอิลิเมนต์ต่าง ๆ

7.6 บรรทัดหมายเหตุ (Comment) ในภาษา HTML คืออะไร? มีรูปแบบการเขียนและประโยชน์อย่างไร?
