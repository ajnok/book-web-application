# 3. ตัวแปรและชนิดข้อมูล

อ้างอิงจากหนังสือ หน้า 388-391

| ตัวอย่างที่ (หนังสือ) | หน้า | คำอธิบาย | ไฟล์ |
|---|---|---|---|
| 1 | 388 | การสร้างและกำหนดค่าให้ตัวแปร | example-01-creating-variables.php |
| 2 | 389-390 | การแปลงชนิดข้อมูลอัตโนมัติ (Type Juggling) | example-02-type-juggling.php |

หมายเหตุ: ตัวอย่างที่ 1 ในหนังสือ (หน้า 388) ไม่มีแท็กเปิด `<?php` และแท็กปิด `?>` ครอบโค้ดไว้ (แสดงเฉพาะ 3 บรรทัดคำสั่ง) จึงคงไว้ตามต้นฉบับโดยไม่เพิ่มแท็กเข้าไป

หัวข้อ 2. ไวยากรณ์ของภาษา PHP (การกำหนดแท็ก การเขียนประโยคคำสั่ง การเขียนคอมเมนต์ คำสำคัญ) และหัวข้อ 2.3-2.4 (นิพจน์ ตัวดำเนินการ) หน้า 382-387 มีเฉพาะกล่องรูปแบบและตารางประกอบคำอธิบาย ไม่มีตัวอย่างที่มีเลขกำกับ (ตัวอย่างที่ ...) จึงไม่ได้สร้างโฟลเดอร์แยกสำหรับหัวข้อดังกล่าว
