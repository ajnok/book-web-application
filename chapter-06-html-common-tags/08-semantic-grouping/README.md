# 8. แท็กสำหรับการจัดกลุ่มเนื้อหาเชิงความหมาย

อ้างอิงจากหนังสือ หน้า 176-183

| ตัวอย่างที่ (หนังสือ) | หน้า | คำอธิบาย | ไฟล์ |
|---|---|---|---|
| 20 | 180-183 | ตัวอย่างการจัดกลุ่มเนื้อหาเชิงความหมายแบบครบถ้วนตามภาพที่ 6.2 โดยใช้แท็ก header, nav, main, article, section, aside และ footer ร่วมกัน (ไฟล์ index.html) | example-20-semantic-tags-full.html |

หมายเหตุ:

- หัวข้อนี้ในหนังสือ (8.1.1 - 8.1.7) มีเฉพาะกล่อง "รูปแบบ" (pattern) แสดงไวยากรณ์เดี่ยว ๆ ของแท็ก header, nav, main, article, section, aside และ footer โดยไม่มีตัวอย่างที่มีเลขกำกับแยกรายแท็ก จนกระทั่งหัวข้อ 8.2 จึงมีตัวอย่างที่ 20 ที่รวมแท็กทั้งหมดไว้ในเอกสารเดียว จึงสร้างไฟล์แยกเฉพาะตัวอย่างที่ 20 เท่านั้น
- ตัวอย่างที่ 20 มีคอมเมนต์บางบรรทัด (ก่อนแท็ก `<nav>` และก่อนแท็ก `<aside>`) ที่ใช้เครื่องหมาย em dash (—) แทนเครื่องหมายขีดคู่ (--) ตามปกติของ HTML Comment กล่าวคือปรากฏเป็น `<!—ส่วนนำทาง -->` และ `<!—ส่วนด้านข้าง -->` แทนที่จะเป็น `<!--...-->` ซึ่งเป็นไปตามต้นฉบับในหนังสือ (หน้า 180-181) จึงคงไว้ตามเดิมโดยไม่แก้ไข แม้ว่ารูปแบบนี้จะไม่ใช่ไวยากรณ์คอมเมนต์ที่ถูกต้องตามมาตรฐาน HTML ก็ตาม
- คำว่า "HyperText Markup Languge" ในย่อหน้าแรกของตัวอย่างสะกดขาดตัวอักษร "a" (ที่ถูกต้องคือ Language) ตามต้นฉบับในหนังสือ (หน้า 181) จึงคงไว้ตามเดิมโดยไม่แก้ไข
