# กิจกรรมท้ายบท - บทที่ 11: ภาษา PHP

อ้างอิงจากหนังสือ หน้า 419-420

8.1 อธิบายความหมายและบทบาทของภาษา PHP ในการพัฒนาเว็บแอปพลิเคชัน พร้อมอธิบายกลไกการทำงานร่วมกันระหว่างซอฟต์แวร์ผู้ให้บริการเว็บและตัวแปลภาษา PHP ตั้งแต่รับคำร้องขอจากผู้ใช้จนส่งผลลัพธ์กลับ

8.2 อธิบายข้อกำหนดที่เกี่ยวข้องกับการสร้างไฟล์ PHP และหลักการกำหนดโครงสร้างของไฟล์ PHP ที่เหมาะสมตามมาตรฐาน PSR-1 และ PSR-12 พร้อมยกตัวอย่างประกอบ

8.3 จงอธิบายแนวคิดของตัวแปรและชนิดข้อมูลในภาษา PHP โดยระบุรูปแบบการประกาศตัวแปร ชนิดข้อมูลพื้นฐานที่ PHP รองรับ และตัวอย่างการใช้งานพอสังเขป

8.4 จงอธิบายแนวคิดของฟังก์ชันในภาษา PHP และยกตัวอย่างการสร้างฟังก์ชันที่รับพารามิเตอร์และส่งค่ากลับอย่างน้อย 1 ตัวอย่าง พร้อมอธิบายผลลัพธ์ที่เกิดขึ้น

8.5 จงอธิบายแนวคิดของอาร์เรย์ในภาษา PHP และเขียนรหัส PHP เพื่อสร้างอาร์เรย์เก็บรายชื่อสินค้าอย่างน้อย 3 รายการ จากนั้นใช้โครงสร้างการวนซ้ำเพื่อแสดงรายชื่อสินค้าแต่ละรายการด้วยฟังก์ชัน echo พร้อมอธิบายโครงสร้างรหัสที่ใช้

8.6 จงสร้างฟอร์ม HTML สำหรับรับค่าจำนวนเต็มสองจำนวน แล้วส่งข้อมูลไปยังไฟล์ PHP เพื่อคำนวณผลรวมและแสดงผลลัพธ์ออกทางเว็บเบราว์เซอร์ ตามภาพที่ 11.2 โดยมีข้อกำหนดดังนี้

- 8.6.1 สร้างไฟล์ sum-form.html เพื่อแสดงฟอร์มรับค่าจำนวนเต็มสองจำนวน โดยกำหนดชื่อช่องรับข้อมูลเป็น number1 และ number2
- 8.6.2 กำหนดให้ฟอร์มในไฟล์ sum-form.html ส่งข้อมูลด้วยวิธี POST ไปยังไฟล์ sum-result.php
- 8.6.3 สร้างไฟล์ sum-result.php เพื่อรับค่าจาก $_POST['number1'] และ $_POST['number2'] พร้อมตรวจสอบว่ามีการส่งค่ามาก่อนประมวลผล
- 8.6.4 เขียนฟังก์ชัน calculateSum($a, $b) เพื่อรับค่าจำนวนเต็มสองจำนวน แล้วส่งค่าผลรวมกลับ
- 8.6.5 เรียกใช้ฟังก์ชัน calculateSum() และแสดงค่าจำนวนที่รับมา รวมทั้งผลรวม ด้วยคำสั่ง echo
- 8.6.6 เปิดไฟล์ sum-form.html ผ่านเว็บเบราว์เซอร์ กรอกค่าตัวเลข ทดสอบการส่งข้อมูล และตรวจสอบผลลัพธ์ที่แสดงจากไฟล์ sum-result.php
- 8.6.7 ทดลองเปลี่ยนการส่งข้อมูลจากฟอร์มในไฟล์ sum-form.html ด้วยวิธี GET และเปลี่ยนการรับค่าในไฟล์ sum-result.php ให้ถูกต้อง

8.7 จงเขียนรหัส PHP ในไฟล์ชื่อ grade.php เพื่อสร้างอาร์เรย์ 2 มิติสำหรับเก็บข้อมูลนักศึกษา และแสดงผลการประเมินคะแนนออกทางเว็บเบราว์เซอร์ โดยมีข้อกำหนดดังนี้

- 8.7.1 สร้างอาร์เรย์ชื่อ $students เป็นอาร์เรย์แบบดัชนีตัวเลข สำหรับเก็บรายการนักศึกษาอย่างน้อย 3 คน โดยสมาชิกแต่ละตัวของอาร์เรย์ $students เป็นอาร์เรย์แบบกำหนดชื่อดัชนี ซึ่งแทนข้อมูลของนักศึกษา 1 คน
- 8.7.2 อาร์เรย์แบบกำหนดชื่อดัชนีของนักศึกษาแต่ละคนต้องมีดัชนี name สำหรับเก็บชื่อนักศึกษาเป็นข้อมูลชนิดข้อความ และดัชนี score สำหรับเก็บคะแนนเป็นข้อมูลชนิดจำนวนเต็ม
- 8.7.3 ใช้โครงสร้างการวนซ้ำ foreach ที่อ่านข้อมูลนักศึกษาแต่ละคนจากอาร์เรย์ $students
- 8.7.4 ใช้คำสั่งเงื่อนไข if-else เพื่อตรวจสอบผลการประเมิน โดยกำหนดให้คะแนนตั้งแต่ 50 คะแนนขึ้นไปมีผลเป็น "ผ่าน" และคะแนนน้อยกว่า 50 คะแนนมีผลเป็น "ไม่ผ่าน"
- 8.7.5 ใช้ฟังก์ชัน echo เพื่อแสดงชื่อนักศึกษา คะแนน และผลการประเมินของนักศึกษาแต่ละคนออกทางเว็บเบราว์เซอร์ ผลลัพธ์ที่คาดหวังแสดงดังภาพที่ 11.3
