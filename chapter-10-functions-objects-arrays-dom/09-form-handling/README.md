# 4.5 การจัดการแบบฟอร์ม

อ้างอิงจากหนังสือ หน้า 367-372

| ตัวอย่างที่ (หนังสือ) | หน้า | คำอธิบาย | ไฟล์ |
|---|---|---|---|
| 43 | 368 | การเข้าถึงอิลิเมนต์ฟอร์มและการดึงค่าข้อมูล | example-43-accessing-form-data.html, form-example-43.js |
| 44 | 369-370 | การตรวจสอบความถูกต้องของข้อมูลฝั่งผู้ใช้ (Client-side Validation) | example-44-client-side-validation.html, validation.js |
| 45 | 371-372 | การจัดการเหตุการณ์ฟอร์มและการป้องกันการส่งข้อมูล (submit, preventDefault) | example-45-submit-and-preventdefault.html, form-handler.js |

หมายเหตุ (คงตามต้นฉบับหนังสือโดยไม่แก้ไข):
- ตัวอย่างที่ 43: หนังสือตั้งชื่อไฟล์ JavaScript ว่า `form-example.js` จึงตั้งชื่อไฟล์ในโฟลเดอร์นี้เป็น `form-example-43.js` เพื่อไม่ให้ชนกับตัวอย่างที่ 44 ที่หนังสือระบุชื่อไฟล์ในตารางเป็น `form-example.js` เช่นกัน (ดูหมายเหตุถัดไป) โดยเนื้อหาโค้ดคงไว้ตามต้นฉบับทุกประการ
- ตัวอย่างที่ 44: หัวตารางโค้ด JavaScript ในหนังสือ (หน้า 369) ระบุชื่อไฟล์ว่า "JavaScript: form-example.js" ซึ่งไม่ตรงกับชื่อไฟล์ที่อ้างอิงจริงในโค้ด HTML ของตัวอย่างเดียวกัน คือ `<script src="validation.js"></script>` (บรรทัดที่ 9) จึงยึดชื่อไฟล์ตามที่ปรากฏใน tag script จริง คือ `validation.js` และคงข้อสังเกตความไม่ตรงกันของหัวตารางไว้ในหมายเหตุนี้
- ตัวอย่างที่ 45 (form-handler.js): บรรทัด `userError = document.getElementById('username-error')` และ `passwordError = document.getElementById('password-error');` ไม่มีการประกาศตัวแปรด้วย let/var/const ก่อนใช้งาน (กลายเป็นตัวแปรโกลบอลโดยปริยาย) และบรรทัดแรกไม่มีเครื่องหมายอัฒภาค (;) ปิดท้าย ตามที่ปรากฏในต้นฉบับหนังสือ (หน้า 371) จึงคงไว้ตามเดิมโดยไม่แก้ไข เช่นเดียวกับ `result=document.getElementById('result');` ที่ไม่มีการประกาศตัวแปรเช่นกัน
