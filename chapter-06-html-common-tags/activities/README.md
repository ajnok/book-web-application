# กิจกรรมท้ายบท - บทที่ 6: แท็ก HTML ที่พบบ่อยในการพัฒนาเว็บแอปพลิเคชัน

อ้างอิงจากหนังสือ หน้า 184-186

10.1 จงอธิบายหน้าที่ของแท็ก HTML ตามกลุ่มแท็กต่อไปนี้ พร้อมยกตัวอย่างแท็กในแต่ละกลุ่มอย่างน้อยกลุ่มละ 1 แท็ก

- 10.1.1 แท็กสำหรับแสดงรูปภาพ
- 10.1.2 แท็กสำหรับสร้างลิงก์
- 10.1.3 แท็กสำหรับกำหนดรายการ
- 10.1.4 แท็กสำหรับกำหนดหัวเรื่องและข้อความ

10.2 จงเลือกแท็ก HTML ที่เหมาะสมสำหรับสถานการณ์ต่อไปนี้ พร้อมอธิบายเหตุผลประกอบ:

- 10.2.1 การแสดงภาพประกอบสินค้า
- 10.2.2 การเชื่อมโยงไปยังหน้าเว็บอื่น
- 10.2.3 การแสดงรายการเมนูอาหาร
- 10.2.4 การแสดงข้อมูลตารางเปรียบราคา
- 10.2.5 การรับข้อมูลอีเมลจากผู้ใช้
- 10.2.6 การจัดกลุ่มส่วนเนื้อหาหลักของหน้าเว็บ

10.3 จงเปรียบเทียบความแตกต่างระหว่างการใช้แท็กสำหรับการจัดกลุ่มเนื้อหาที่ไม่มีความหมายเชิงเนื้อหา (เช่น div และ span) กับแท็กสำหรับการจัดกลุ่มเนื้อหาเชิงความหมาย (เช่น header, nav, main, section, article, aside และ footer) พร้อมยกตัวอย่างสถานการณ์ที่ควรใช้แท็กแต่ละกลุ่ม

10.4 จงเขียนรหัส HTML เพื่อสร้างตารางแสดงรายการสินค้าอย่างน้อย 3 แถว โดยใช้โครงสร้างของตารางให้ครบถ้วน ได้แก่ ส่วนหัวของตาราง ส่วนเนื้อหาของตาราง และเซลล์ข้อมูลในแต่ละแถว พร้อมอธิบายหน้าที่ของแท็กที่ใช้ในตารางพอสังเขป

10.5 จงเขียนหน้าเว็บโดยใช้ภาษา HTML บันทึกไฟล์ชื่อ member.html เพื่อสร้างฟอร์มที่มีช่องกรอกข้อมูลชื่อ สกุล และหมายเลขโทรศัพท์ รวมทั้งช่องตัวเลือกข้อมูลระดับการศึกษา ปุ่มส่ง และปุ่มรีเซ็ต โดยกำหนดให้ฟอร์มส่งข้อมูลไปยังไฟล์ชื่อ record.php และใช้วิธีการส่งข้อมูลแบบ GET

10.6 จากภาพผลลัพธ์ของหน้าเว็บต่อไปนี้ จงเขียนหน้าเว็บโดยใช้ภาษา HTML โดยตั้งชื่อไฟล์เป็น index.html ทั้งนี้ยังไม่ต้องทำการกำหนดรูปแบบใดโดยใช้ CSS (อ้างอิงภาพที่ 6.3 ตัวอย่างการจัดกลุ่มเนื้อหาและบทบาทของเนื้อหาในเอกสารเว็บ)

- 10.6.1 กำหนดโครงสร้างเอกสาร HTML ให้ครบถ้วนตามรูปแบบพื้นฐานของเอกสารเว็บ ได้แก่ การประกาศชนิดเอกสาร ส่วน html ส่วน head และส่วน body พร้อมกำหนดชื่อหน้าเว็บให้เหมาะสมกับเนื้อหา
- 10.6.2 จัดกลุ่มส่วนประกอบหลักของหน้าเว็บด้วยแท็กเชิงความหมาย ได้แก่ header, nav, main, aside และ footer เพื่อแสดงให้เห็นบทบาทของเนื้อหาแต่ละส่วนอย่างชัดเจนตามภาพประกอบ
- 10.6.3 ในส่วน header ให้แสดงชื่อเว็บไซต์หรือชื่อหน่วยงานเป็นหัวเรื่องระดับที่ 1 โดยใช้ข้อความว่า "มหาวิทยาลัยราชภัฏกำแพงเพชร แม่สอด" และให้เพิ่มข้อความภาษาอังกฤษขนาดเล็กใต้ชื่อหน่วยงานตามความเหมาะสม
- 10.6.4 ในส่วน nav ให้สร้างรายการเชื่อมโยงเมนูนำทางอย่างน้อย 5 รายการ ได้แก่ หน้าแรก, เกี่ยวกับเรา, หลักสูตร, ข่าวสาร และ ติดต่อ โดยกำหนดค่า href ของลิงก์เป็น # เพื่อใช้เป็นตัวอย่างการสร้างลิงก์ภายในหน้าเว็บ
- 10.6.5 ในส่วน main ให้สร้างหัวเรื่องระดับที่ 2 สำหรับหัวข้อ "ประวัติความเป็นมา" และเขียนย่อหน้าสั้น ๆ เพื่อแสดงเนื้อหาเกี่ยวกับความเป็นมาของหน่วยงานหรือเว็บไซต์
- 10.6.6 ภายในส่วน main ให้สร้างหัวเรื่องระดับที่ 3 สำหรับหัวข้อ "หลักการที่เปิดสอน" แล้วแสดงรายการหลักสูตรในรูปแบบรายการแบบไม่มีลำดับ โดยมีรายการอย่างน้อย 3 รายการ เช่น บริหารธุรกิจบัณฑิต เทคโนโลยีธุรกิจดิจิทัล และรัฐประศาสนศาสตรบัณฑิต
- 10.6.7 สร้างหัวเรื่องระดับที่ 3 สำหรับหัวข้อ "ความสำเร็จที่ผ่านมา" แล้วแสดงรายการข้อมูลในรูปแบบรายการแบบมีลำดับ โดยมีข้อมูลอย่างน้อย 3 รายการ
- 10.6.8 สร้างตารางแสดงข้อมูลจำนวนนักศึกษาหรือข้อมูลสถิติที่เกี่ยวข้อง โดยตารางต้องมีคอลัมน์อย่างน้อย 3 คอลัมน์ ได้แก่ ปีการศึกษา, จำนวน (คน) และ ร้อยละ และมีข้อมูลอย่างน้อย 3 แถว พร้อมกำหนดโครงสร้างตารางให้ครบถ้วน ได้แก่ ส่วนหัวของตาราง แถวของตาราง และเซลล์ข้อมูล
- 10.6.9 หลังตาราง ให้เพิ่มส่วน "แหล่งข้อมูลอ้างอิง" โดยใช้หัวเรื่องระดับที่ 3 และแสดงรายการลิงก์อ้างอิงอย่างน้อย 2 รายการ ในรูปแบบรายการแบบไม่มีลำดับ โดยกำหนดค่า href ของแต่ละลิงก์เป็น #
- 10.6.10 ในส่วน aside ให้สร้างหัวเรื่องระดับที่ 3 จำนวนอย่างน้อย 2 หัวข้อ เช่น "ข่าวล่าสุด" และ "ข่าวประชาสัมพันธ์" แล้วแสดงรายการข่าวเป็นรายการแบบไม่มีลำดับ โดยแต่ละรายการให้กำหนดเป็นลิงก์ตัวอย่างด้วยค่า href="#"
- 10.6.11 ในส่วน footer ให้แสดงข้อความลิขสิทธิ์ของเว็บไซต์ และเพิ่มลิงก์อย่างน้อย 2 รายการ เช่น เกี่ยวกับเรา และ ติดต่อเรา โดยกำหนดค่า href เป็น #
- 10.6.12 ให้ตรวจสอบว่าเอกสาร HTML ที่สร้างขึ้นมีการเลือกใช้แท็กสอดคล้องกับบทบาทของเนื้อหา เช่น ใช้หัวเรื่องตามลำดับความสำคัญ ใช้รายการแบบมีลำดับหรือไม่มีลำดับให้เหมาะสม ใช้ตารางสำหรับข้อมูลที่มีโครงสร้างเป็นแถวและคอลัมน์ และใช้แท็กเชิงความหมายในการจัดกลุ่มส่วนประกอบหลักของหน้าเว็บ
