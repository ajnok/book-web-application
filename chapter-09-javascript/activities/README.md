# กิจกรรมท้ายบท - บทที่ 9: ภาษา JavaScript

อ้างอิงจากหนังสือ หน้า 316

6.1 จงอธิบายความหมายของภาษา JavaScript และบทบาทของภาษา JavaScript ในการพัฒนาเว็บแอปพลิเคชัน พร้อมระบุว่ามาตรฐาน ECMAScript มีความสำคัญต่อการพัฒนาและใช้งาน JavaScript อย่างไร

6.2 ประโยคคำสั่งในภาษา JavaScript มีลักษณะอย่างไร? จงยกตัวอย่างประโยคคำสั่งที่ถูกต้องมา 2 ตัวอย่าง พร้อมอธิบายหน้าที่ของแต่ละคำสั่ง

6.3 จงอธิบายความหมายและยกตัวอย่างของนิพจน์ในภาษา JavaScript พร้อมทั้งระบุประเภทของนิพจน์อย่างน้อย 3 ประเภท

6.4 จงเปรียบเทียบความแตกต่างระหว่างการประกาศตัวแปรด้วย var, let และ const ในด้านขอบเขตการใช้งาน (Scope) การกำหนดค่าใหม่ และการยกระดับ (Hoisting) พร้อมยกตัวอย่างการใช้งานที่เหมาะสมของแต่ละชนิด

6.5 ข้อมูลประเภทพื้นฐาน (Primitive Data Types) ของภาษา JavaScript มีอะไรบ้าง? จงอธิบายแต่ละประเภทโดยสังเขป พร้อมยกตัวอย่างค่าของแต่ละประเภท

6.6 จงเขียนรหัส JavaScript เพื่อประมวลผลต่อไปนี้

- 6.6.1 ประกาศตัวแปรเก็บค่าคะแนน (0-100) ด้วย let จากนั้นใช้โครงสร้างการตัดสินใจแบบ if-else เพื่อตรวจสอบว่าคะแนนอยู่ในระดับ "ผ่าน" (คะแนนมากกว่าหรือเท่ากับ 50) หรือ "ไม่ผ่าน (คะแนนน้อยกว่า 50)" แล้วแสดงผลด้วย console.log()
- 6.6.2 เขียนโครงสร้างการวนซ้ำแบบ for เพื่อแสดงตัวเลข 1 ถึง 5 ออกทาง console พร้อมอธิบายการทำงานของโครงสร้างการวนซ้ำที่ใช้
