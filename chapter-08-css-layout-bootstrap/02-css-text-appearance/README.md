อ้างอิงจากหนังสือ หน้า 228-237

| ตัวอย่างที่ (หนังสือ) | หน้า | คำอธิบาย | ไฟล์ |
|---|---|---|---|
| 5 | 229 | คุณสมบัติในการจัดตำแหน่งข้อความและอิลิเมนต์ (text-align, text-indent, line-height, text-transform) | example-05-text-properties.css, example-05-text-properties.html |
| 6 | 230 | คุณสมบัติในการกำหนดแบบตัวอักษร (font-family, font-size, font-style, font-weight, font แบบย่อ) | example-06-font-properties.css, example-06-font-properties.html |
| 7 | 232 | คุณสมบัติในการจัดการพื้นหลังของอิลิเมนต์ (background-color, background-image, background-repeat, background-position, background แบบย่อ) | example-07-background-properties.css, example-07-background-properties.html |

หมายเหตุ:

- ตัวอย่างที่ 6 คอลัมน์ CSS ในหนังสือ (หน้า 230) มีข้อความของค่า `font` แบบย่อของคลาส `.font2` ถูกตัดขึ้นบรรทัดใหม่กลางค่าสตริง `"Times New Roman"` เนื่องจากพื้นที่ของตารางในหน้าหนังสือไม่พอ ซึ่งเป็นการตัดคำเพื่อการจัดหน้าเท่านั้น ไม่ใช่การขึ้นบรรทัดจริงในโค้ด จึงเขียนกลับให้เป็นบรรทัดเดียวกันตามเจตนาของโค้ดต้นฉบับ
- ตัวอย่างที่ 7 และ 9 ในหนังสือแสดงเป็นตารางสองคอลัมน์ (CSS และ HTML) จึงแยกบันทึกเป็น 2 ไฟล์ต่อหนึ่งตัวอย่าง
