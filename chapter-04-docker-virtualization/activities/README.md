# กิจกรรมท้ายบท - บทที่ 4: การสร้างกลไกผู้ให้บริการเว็บด้วยแนวคิดการจำลองเสมือนในสภาพแวดล้อมการพัฒนา

อ้างอิงจากหนังสือ หน้า 117-118

5.1 แนวคิดการจำลองเสมือนมีลักษณะเป็นอย่างไร? และมีเทคโนโลยีหลักใดบ้างที่อยู่ภายใต้แนวคิดนี้? จงอธิบายพอสังเขป

5.2 จงให้ความหมายของเทคโนโลยีเครื่องเสมือน พร้อมทั้งบอกประโยชน์และข้อจำกัดของเทคโนโลยีเครื่องเสมือนในการพัฒนาเว็บแอปพลิเคชันพอสังเขป

5.3 จงให้ความหมายของเทคโนโลยีคอนเทนเนอร์ พร้อมทั้งบอกประโยชน์และข้อจำกัดของเทคโนโลยีคอนเทนเนอร์ในการพัฒนาเว็บแอปพลิเคชันพอสังเขป

5.4 เทคโนโลยีเครื่องเสมือนและเทคโนโลยีคอนเทนเนอร์แตกต่างกันอย่างไรในด้านสถาปัตยกรรม การใช้ทรัพยากร และความเหมาะสมกับงานพัฒนาเว็บแอปพลิเคชัน? จงอธิบายพอสังเขป

5.5 จงอธิบายส่วนประกอบของกลไกการทำงานของ Docker Desktop ต่าง ๆ ต่อไปนี้

- 5.5.3 คอนเทนเนอร์

5.6 ทดลองติดตั้งโปรแกรม Docker Desktop และทำการสร้างสภาพแวดล้อมการพัฒนาเว็บแอปพลิเคชันด้วย LAMP Stack ตามขั้นตอนต่อไปนี้

5.6.1 สร้างโฟลเดอร์ใหม่โครงสร้างดังภาพที่ 4.18 ในหนังสือ:

```text
C:\webapp\
└── source\
    ├── css\
    ├── js\
    ├── image\
    └── index.php
compose.yaml
```

5.6.2 สร้างไฟล์ `compose.yaml` ในตำแหน่งดังภาพที่ 4.18 เพื่อใช้ในการสร้างบริการและคอนเทนเนอร์ต่อไปนี้ (เนื้อหาไฟล์เป็นแบบฝึกหัดที่ผู้อ่านต้องเขียนขึ้นเอง หนังสือให้เฉพาะข้อกำหนดของแต่ละบริการ ไม่ได้ให้โค้ดสำเร็จรูปในกิจกรรมนี้):

- บริการชื่อ `db` ใช้แม่แบบคอนเทนเนอร์ `mysql:8.4.5` เพื่อสร้างคอนเทนเนอร์ชื่อ `dbserver` กำหนดให้มีการเปิดใช้งานพอร์ต 3306 เพื่อให้บริการอื่นสามารถเชื่อมต่อได้โดยไม่เปิดเผยพอร์ตสู่เครื่องโฮสต์ และเชื่อมโยงพื้นที่จัดเก็บข้อมูลภายในคอนเทนเนอร์กับ Docker Volume ชื่อ `db_data` รวมทั้งกำหนดค่าตัวแปรสภาพแวดล้อมดังนี้: รหัสผ่านผู้ดูแลระบบฐานข้อมูลเป็น `rootpass`, ฐานข้อมูลชื่อ `db_webapp`, ผู้ใช้ฐานข้อมูลชื่อ `webapp_user`, รหัสผ่านของผู้ใช้ฐานข้อมูลเป็น `userpass`
- บริการชื่อ `web` ใช้แม่แบบคอนเทนเนอร์ `php:8.3-apache` เพื่อสร้างคอนเทนเนอร์ชื่อ `webserver` กำหนดให้มีการเปิดใช้งานพอร์ต 80:80 และทำการเชื่อมโยงโฟลเดอร์ `source` ไปยัง `/var/www/html` ของคอนเทนเนอร์ webserver รวมทั้งมีการกำหนดให้บริการ web เริ่มต้นหลังจากบริการ db ทำงานแล้ว
- บริการชื่อ `dbmanager` ใช้แม่แบบคอนเทนเนอร์ `phpmyadmin:5.2.2-apache` เพื่อสร้างคอนเทนเนอร์ชื่อ `phpmyadmin` กำหนดให้มีการเชื่อมโยงพอร์ต 88:80 และกำหนดตัวแปรสภาพแวดล้อม `PMA_HOST` เป็น `db` ซึ่งเป็นชื่อบริการของคอนเทนเนอร์ฐานข้อมูล รวมทั้งมีการกำหนดให้บริการ dbmanager เริ่มต้นหลังจากบริการ db ทำงานแล้ว

5.6.3 สร้างไฟล์ `index.php` ในตำแหน่งดังภาพที่ 4.18 เพื่อใช้ในการทดสอบการทำงานของบริการเว็บ เนื้อหาในไฟล์มีดังนี้ (ดูไฟล์ [index.php](./index.php) ในโฟลเดอร์นี้)

5.6.4 สร้างคอนเทนเนอร์จากไฟล์ `compose.yaml` ที่ได้สร้างขึ้น

5.6.5 ตรวจสอบผลการสร้างคอนเทนเนอร์และทดสอบการทำงานของคอนเทนเนอร์ดังนี้

- ทดสอบการทำงานของคอนเทนเนอร์ให้บริการเว็บด้วยการเปิดเว็บเบราว์เซอร์และเข้าถึงด้วย http://localhost
- ทดสอบการทำงานของคอนเทนเนอร์ให้บริการฐานข้อมูลด้วยการเปิดเว็บเบราว์เซอร์และเข้าถึงด้วย http://localhost:88
