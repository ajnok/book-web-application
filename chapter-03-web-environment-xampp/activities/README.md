# กิจกรรมท้ายบท - บทที่ 3: สภาพแวดล้อมเว็บแอปพลิเคชันและการสร้างกลไกให้บริการเว็บด้วยโปรแกรมสำเร็จรูป

อ้างอิงจากหนังสือ "การพัฒนาเว็บแอปพลิเคชัน: แนวคิดและหลักการสู่การปฏิบัติสำหรับผู้เริ่มต้น" หน้า 80

> หมายเหตุ: บทที่ 3 เป็นบทที่แนะนำสภาพแวดล้อมเว็บแอปพลิเคชันและขั้นตอนการติดตั้ง XAMPP ผ่านภาพประกอบและคำอธิบาย ไม่มีโค้ดตัวอย่าง (ตัวอย่างที่ N) ให้ดึงมาเป็นไฟล์ จึงมีเฉพาะกิจกรรมท้ายบทในโฟลเดอร์นี้

## กิจกรรมท้ายบท

6.1 จงอธิบายความหมายของสภาพแวดล้อมเว็บแอปพลิเคชัน

6.2 สภาพแวดล้อมเว็บแอปพลิเคชันแบ่งได้เป็น 2 ลักษณะ มีอะไรบ้าง? จงให้คำนิยามและอธิบายความแตกต่างของสภาพแวดล้อมทั้งสองพอสังเขป

6.3 องค์ประกอบของสภาพแวดล้อมการพัฒนามีอะไรบ้าง? และแต่ละองค์ประกอบมีบทบาทอย่างไรในการสร้างกลไกให้บริการเว็บ?

6.4 Software Stack ที่ใช้ในการสร้างกลไกให้บริการเว็บคืออะไร? ประกอบด้วยโปรแกรมหลักอะไรบ้าง? ยกตัวอย่างชื่อเรียก Software Stack มาอย่างน้อย 3 ชื่อ พร้อมระบุระบบปฏิบัติการที่รองรับ

6.5 การสร้างกลไกให้บริการเว็บในสภาพแวดล้อมการพัฒนาโดยใช้โปรแกรมสำเร็จรูปมีข้อดีและข้อจำกัดอย่างไรบ้าง? จงอธิบายพอสังเขป และระบุสถานการณ์ที่เหมาะสมต่อการใช้งาน

6.6 ให้ติดตั้ง XAMPP แล้วเปิดใช้งาน Apache และ MySQL จากนั้นทดสอบการทำงานโดยเข้าถึง http://localhost และ http://localhost/phpmyadmin ผ่านเว็บเบราว์เซอร์
