# 4. การแสดงผลด้วยฟังก์ชัน echo และ print

อ้างอิงจากหนังสือ หน้า 392-398

| ตัวอย่างที่ (หนังสือ) | หน้า | ไฟล์ตามหนังสือ | คำอธิบาย | ไฟล์ |
|---|---|---|---|---|
| 3 | 393 | index.php | ฟังก์ชัน echo | example-03-echo.php |
| 4 | 393-394 | index-2.php | ฟังก์ชัน echo ร่วมกับแท็ก HTML และการใช้เครื่องหมายอัญประกาศคู่/เดี่ยว | example-04-echo-with-html.php |
| 5 | 395 | index-3.php | ฟังก์ชัน print | example-05-print.php |

หมายเหตุ (คงตามต้นฉบับหนังสือโดยไม่แก้ไข):
- ตัวอย่างที่ 3 และ 5: ไม่มีแท็กปิด `?>` ท้ายไฟล์ ตามที่ปรากฏในต้นฉบับหนังสือ (หน้า 393, 395) ซึ่งเป็นแนวปฏิบัติที่หนังสือกล่าวถึงไว้ในหัวข้อ 2.2.1 (การละแท็กปิดในไฟล์ PHP ที่มีเพียงรหัสคำสั่งภาษา PHP)
- ตัวอย่างที่ 6: บรรทัดที่ 13 พิมพ์เป็น `<?phpecho $title;  ?>` โดยไม่มีการเว้นวรรคระหว่างแท็กเปิด `<?php` กับคำสั่ง `echo` ตามที่ปรากฏในต้นฉบับหนังสือ (หน้า 396) จึงคงไว้ตามเดิมโดยไม่แก้ไข แม้ว่าโดยหลักไวยากรณ์ของภาษา PHP จะต้องมีช่องว่างหรือการขึ้นบรรทัดใหม่คั่นระหว่างแท็กเปิดกับคำสั่งถัดไป
- ตัวอย่างที่ 6: มีการเว้นวรรคซ้ำหลายตำแหน่ง เช่น `<span  style="color:blue;">` และ `<?php  echo $name;  ?>` ตามต้นฉบับหนังสือ จึงคงไว้ตามเดิม
- ตัวอย่างที่ 6: แท็ก `<span style="color: blue;" onclick="alert('...')...">` ถูกพิมพ์แยกเป็น 2 บรรทัดในหนังสือ (บรรทัดที่ 25 ตามเลขกำกับของหนังสือ) จึงคงการแยกบรรทัดไว้ตามเดิม
