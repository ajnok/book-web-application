# กิจกรรมท้ายบท - บทที่ 12: การจัดการข้อมูลจากผู้ใช้ด้วย PHP

อ้างอิงจากหนังสือ หน้า 475-476

5.1 อธิบายลำดับขั้นตอนของการรับค่าจากฟอร์ม HTML สู่การประมวลผลด้วยภาษา PHP โดยอธิบายการใช้ตัวแปร $_GET และ $_POST ว่ามีความแตกต่างกันอย่างไร พร้อมยกตัวอย่างคำสั่งที่เกี่ยวข้อง

5.2 จงอธิบายความแตกต่างระหว่างการตรวจสอบข้อมูลกับการล้างข้อมูล พร้อมยกตัวอย่างฟังก์ชันที่เหมาะสมในแต่ละกรณี ประกอบด้วย is_numeric(), htmlspecialchars(), trim() และ filter_var()

5.3 ให้อธิบายโครงสร้างคำสั่งในการเชื่อมต่อฐานข้อมูล MySQL ด้วย PDO พร้อมระบุบทบาทของ DSN, ชื่อผู้ใช้, รหัสผ่าน, การกำหนดโหมดแสดงข้อผิดพลาด และข้อดีของการใช้ PDO เมื่อเปรียบเทียบกับการใช้ mysqli โดยตรง

5.4 จงอธิบายความสัมพันธ์ระหว่างแนวคิด CRUD กับคำสั่ง SQL ที่ใช้ในการจัดการข้อมูลในเว็บแอปพลิเคชัน โดยระบุว่า Create, Read, Update และ Delete มีความหมายอย่างไร และสัมพันธ์กับคำสั่ง INSERT, SELECT, UPDATE และ DELETE ของ SQL อย่างไร พร้อมยกตัวอย่างสถานการณ์การใช้งานจากระบบจัดการผู้ใช้ในบทนี้

- 5.4.1 อธิบายความหมายของ Create และระบุว่าตรงกับคำสั่ง SQL ใดในระบบจัดการผู้ใช้
- 5.4.2 อธิบายความหมายของ Read และระบุว่าตรงกับคำสั่ง SQL ใดในระบบจัดการผู้ใช้
- 5.4.3 อธิบายความหมายของ Update และระบุว่าตรงกับคำสั่ง SQL ใดในระบบจัดการผู้ใช้
- 5.4.4 อธิบายความหมายของ Delete และระบุว่าตรงกับคำสั่ง SQL ใดในระบบจัดการผู้ใช้

5.5 จากโครงสร้างหน้าเว็บของระบบ CRUD เบื้องต้น จงอธิบายหน้าที่ของแต่ละไฟล์ ได้แก่ config.php, index.php, add.php, add_process.php, edit.php, edit_process.php และ delete_process.php และอธิบายกลไกการเชื่อมโยงระหว่างไฟล์เหล่านี้ โดยอ้างอิงจากกรณีศึกษาในบทนี้

5.6 ทดลองเขียนระบบ CRUD สำหรับจัดการข้อมูลสมาชิก โดยใช้ฐานข้อมูล MySQL และภาษา PHP ผ่าน PDO พร้อมแสดงผลข้อมูลในรูปแบบตาราง HTML โดยระบบต้องประกอบด้วยไฟล์ config.php, index.php, add.php, add_process.php, edit.php, edit_process.php และ delete_process.php ดังนี้

- 5.6.1 สร้างฐานข้อมูลและตาราง members สำหรับเก็บข้อมูลสมาชิก โดยมีฟิลด์ id, name, email, tel และ address
- 5.6.2 สร้างไฟล์ config.php สำหรับกำหนดค่าการเชื่อมต่อฐานข้อมูล และสร้างอ็อบเจกต์ PDO เพื่อให้ไฟล์อื่นสามารถเรียกใช้งานฐานข้อมูลร่วมกันได้
- 5.6.3 สร้างไฟล์ index.php เพื่อดึงข้อมูลสมาชิกทั้งหมดจากฐานข้อมูล และแสดงผลในรูปแบบตาราง HTML พร้อมปุ่มหรือลิงก์สำหรับเพิ่ม แก้ไข และลบข้อมูล
- 5.6.4 สร้างไฟล์ add.php สำหรับแสดงฟอร์มเพิ่มสมาชิกใหม่ และสร้างไฟล์ add_process.php สำหรับรับค่าจากฟอร์ม ตรวจสอบข้อมูลเบื้องต้น และบันทึกข้อมูลด้วย Prepared Statements
- 5.6.5 สร้างไฟล์ edit.php สำหรับรับค่า id ของสมาชิก ดึงข้อมูลเดิมมาแสดงในฟอร์ม และสร้างไฟล์ edit_process.php สำหรับรับค่าที่แก้ไข ตรวจสอบข้อมูล และอัปเดตข้อมูลด้วย Prepared Statements
- 5.6.6 สร้างไฟล์ delete_process.php สำหรับรับค่า id ของสมาชิก ตรวจสอบว่ามีข้อมูลอยู่จริง และลบข้อมูลออกจากฐานข้อมูล พร้อมให้มีการยืนยันการลบก่อนดำเนินการ
- 5.6.7 ทดสอบระบบโดยเพิ่มข้อมูลสมาชิกอย่างน้อย 3 รายการ จากนั้นทดลองแสดงรายการ แก้ไขข้อมูล ลบข้อมูล และตรวจสอบว่าผลลัพธ์ในหน้า index.php เปลี่ยนแปลงถูกต้องตามการทำงานของระบบ

5.7 จงอธิบายความเสี่ยงของการโจมตีแบบ SQL Injection ในเว็บแอปพลิเคชัน โดยยกตัวอย่างรหัสคำสั่ง PHP ที่มีความเสี่ยงและรหัสคำสั่งที่ปรับปรุงให้ปลอดภัยโดยใช้ PDO Prepared Statements
