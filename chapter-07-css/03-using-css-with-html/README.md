หมายเหตุ:

- ตัวอย่างที่ 4 บรรทัดที่ 12 มีข้อความ "หัวข้อเรื่องรัดบ 2" ปรากฏอยู่ในหนังสือ (หน้า 197) ซึ่งสันนิษฐานว่าเป็นการพิมพ์คลาดเคลื่อนจาก "หัวข้อเรื่องระดับ 2" แต่เนื่องจากต้องคงโค้ดไว้ตามต้นฉบับ จึงไม่มีการแก้ไข
- ตัวอย่างที่ 6 หัวเรื่อง h1 ใช้ข้อความ "ตัวอย่างการใช้ตัวเลือกแบบคลาส" ซ้ำกับตัวอย่างที่ 5 ทั้งที่เนื้อหาเป็นเรื่องตัวเลือกแบบรหัสประจำอิลิเมนต์ ตามต้นฉบับในหนังสือ (หน้า 201) จึงคงไว้ตามเดิมโดยไม่แก้ไข
- ตัวอย่างที่ 7-13 ในหนังสือแสดงเฉพาะโค้ด CSS (ชุดภัณฑ์/Ruleset) โดยไม่มีเอกสาร HTML ประกอบ จึงบันทึกไฟล์เป็นนามสกุล .css ตามลักษณะเนื้อหาที่ปรากฏจริงในหนังสือ
