# กิจกรรมท้ายบท - บทที่ 8: การกำหนดลักษณะการแสดงผลและการสร้างองค์ประกอบของเว็บแอปพลิเคชันด้วย CSS

อ้างอิงจากหนังสือ หน้า 266-268

6.1 จงอธิบายหน้าที่ของคุณสมบัติ CSS ที่ใช้ในการจัดรูปแบบอิลิเมนต์ ประกอบด้วย การควบคุมขนาด เส้นขอบ ระยะห่างภายใน ระยะห่างภายนอก การจัดตำแหน่งข้อความ แบบตัวอักษร พื้นหลัง ลิงก์ และตาราง พร้อมยกตัวอย่างประกอบ

6.2 จงเขียนรหัส HTML และ CSS เพื่อสร้างอิลิเมนต์ div จำนวน 2 อิลิเมนต์ โดยกำหนดขนาดความสูง/ความกว้าง (width/height) เส้นขอบ (border) ระยะห่างภายใน (padding) และระยะห่างภายนอก (margin) ให้แตกต่างกัน พร้อมอธิบายผลลัพธ์ที่เกิดขึ้นกับอิลิเมนต์ทั้งสองตามหลักการ Box Model

6.3 จงอธิบายหลักการจัดวางอิลิเมนต์ด้วย CSS Flexbox โดยกล่าวถึงแนวคิดของแกนหลัก (Main Axis) และแกนข้าม (Cross Axis) ทิศทางการจัดวาง (flex-direction) และการจัดตำแหน่ง (justify-content และ align-items) พร้อมยกตัวอย่างกรณีที่ควรใช้ Flexbox ในการพัฒนาเว็บแอปพลิเคชัน

6.4 จงอธิบายหลักการจัดวางอิลิเมนต์ด้วย CSS Grid โดยกล่าวถึงแนวคิดของแถว (Row) คอลัมน์ (Column) และพื้นที่ (Grid Area) พร้อมยกตัวอย่างกรณีที่ควรเลือกใช้ Grid แทน Flexbox

6.5 จงอธิบายความหมายและประโยชน์ของ CSS Framework

6.6 Bootstrap CSS Framework มีหลักการทำงานร่วมกับ HTML อย่างไร? จงอธิบายแนวทางการใช้ Bootstrap โดยอ้างอิงจากกลไกการทำงานของคลาสใน HTML และระบบ Grid ของ Bootstrap

6.7 จงสร้างเอกสาร HTML ชื่อ booking.html และใช้ Bootstrap CSS Framework เพื่อสร้างหน้าเว็บแสดงข้อมูลระบบจองห้องพัก โดยให้มีโครงสร้างและองค์ประกอบใกล้เคียงกับภาพที่ 8.9 ทั้งนี้ไม่จำเป็นต้องจัดตำแหน่งหรือสีให้เหมือนภาพทุกประการ แต่ต้องใช้องค์ประกอบของ Bootstrap ให้ถูกต้องตามที่ศึกษาในบท โดยมีข้อกำหนดดังนี้

- 6.7.1 สร้างส่วนหัวของหน้าเว็บ โดยใช้คลาส .container หรือ .container-fluid และแสดงข้อความชื่อระบบว่า "ระบบจองห้องพัก" พร้อมข้อความภาษาอังกฤษขนาดเล็กว่า "Hotel Room Booking System"
- 6.7.2 สร้างปุ่มจำนวน 2 ปุ่ม ได้แก่ "จองห้อง" และ "ดูรายการจอง" โดยใช้คลาส .btn และคลาสสีของ Bootstrap เช่น .btn-primary, .btn-secondary หรือ .btn-outline-primary
- 6.7.3 สร้างตารางแสดงรายการห้องพักจำนวนอย่างน้อย 3 แถว โดยใช้คลาส .table และ .table-striped และกำหนดให้ตารางมีคอลัมน์ดังนี้ ลำดับ, หมายเลขห้อง, ประเภทห้อง, ราคา/คืน (บาท) และ สถานะ
- 6.7.4 กำหนดข้อมูลในตารางให้มีอย่างน้อย 3 รายการ เช่น ห้องเดี่ยว ห้องคู่ และห้องสวีท พร้อมกำหนดสถานะของห้อง เช่น "ว่าง" หรือ "ไม่ว่าง"
- 6.7.5 ใช้คลาส Bootstrap เพิ่มเติมเพื่อปรับลักษณะของตารางหรือสถานะของห้องอย่างน้อย 1 รายการ เช่น .table-bordered, .table-hover, .badge, .text-bg-success หรือ .text-bg-danger ตามความเหมาะสม
- 6.7.6 ใช้การจัดวางโครงร่างด้วย Flex หรือ Grid เพื่อจัดวางส่วนหัว ส่วนปุ่ม และส่วนตาราง
