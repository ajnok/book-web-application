# 3. กรณีศึกษา: การสร้าง LAMP Stack ด้วย Docker Desktop

อ้างอิงจากหนังสือ หน้า 104-115

โครงสร้างโฟลเดอร์ตามภาพที่ 4.9 ในหนังสือ (เฉพาะไฟล์ที่หนังสือให้เนื้อหาโค้ดจริง คือ `compose.yaml` และ `source/index.php` ส่วนโฟลเดอร์ `css/`, `js/`, `image/` เป็นโฟลเดอร์ว่างสำหรับให้ผู้อ่านจัดเก็บไฟล์เว็บแอปพลิเคชันของตนเองในภายหลัง):

```text
webapp/
├── source/
│   └── index.php
└── compose.yaml
```

| ไฟล์ (ในหนังสือ) | หน้า | คำอธิบาย | ไฟล์ในโฟลเดอร์นี้ |
|---|---|---|---|
| C:\webapp\compose.yaml | 108-109 | ไฟล์กำหนดบริการ (services) 3 หน่วย ได้แก่ web (webserver), db (dbserver) และ dbmanager สำหรับสร้างคอนเทนเนอร์ LAMP Stack ด้วย Docker Compose | compose.yaml |
| C:\webapp\source\index.php | 113-114 | ไฟล์ทดสอบการทำงานของคอนเทนเนอร์ webserver ร่วมกับ PHP โดยใช้ฟังก์ชัน `phpinfo()` | source/index.php |

หมายเหตุ: ไฟล์ทั้งสองนี้คัดลอกตรงจากตารางโค้ดในหนังสือ ไม่มีการแก้ไขเนื้อหาใดๆ
