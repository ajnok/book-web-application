# 4. การแสดงผลด้วยฟังก์ชัน echo และ print

อ้างอิงจากหนังสือ หน้า 392-398

| ตัวอย่างที่ (หนังสือ) | หน้า | ไฟล์ตามหนังสือ | คำอธิบาย | ไฟล์ |
|---|---|---|---|---|
| 3 | 393 | index.php | ฟังก์ชัน echo | example-03-echo.php |
| 4 | 393-394 | index-2.php | ฟังก์ชัน echo ร่วมกับแท็ก HTML และการใช้เครื่องหมายอัญประกาศคู่/เดี่ยว | example-04-echo-with-html.php |
| 5 | 395 | index-3.php | ฟังก์ชัน print | example-05-print.php |
| 6 | 396-397 | index-4.php | การประยุกต์ใช้คำสั่งแสดงผลร่วมกับแนวคิดการแยกส่วนการทำงาน (Embedded PHP) | example-06-embedded-php.php |

หมายเหตุ (คงตามต้นฉบับหนังสือโดยไม่แก้ไข เว้นแต่จุดที่ระบุไว้ว่า "แก้ไขแล้ว"):
- ตัวอย่างที่ 3 และ 5: ไม่มีแท็กปิด `?>` ท้ายไฟล์ ตามที่ปรากฏในต้นฉบับหนังสือ (หน้า 393, 395) ซึ่งเป็นแนวปฏิบัติที่หนังสือกล่าวถึงไว้ในหัวข้อ 2.2.1 (การละแท็กปิดในไฟล์ PHP ที่มีเพียงรหัสคำสั่งภาษา PHP)
- **ตัวอย่างที่ 6 (แก้ไขแล้ว)**: ต้นฉบับหนังสือ (หน้า 396) พิมพ์บรรทัดที่ 13 เป็น `<?phpecho $title;  ?>` โดยไม่มีการเว้นวรรคระหว่างแท็กเปิด `<?php` กับคำสั่ง `echo` ซึ่งตามหลักไวยากรณ์ของ PHP ทำให้แท็กเปิดไม่ถูกจดจำและเกิด Parse error หากนำไปรันจริง ตามคำขอของผู้เขียนจึงแก้ไขไฟล์ `example-06-embedded-php.php` โดยเติมช่องว่างให้เป็น `<?php echo $title;  ?>` เพื่อให้โค้ดสามารถรันได้ถูกต้อง (เป็นข้อยกเว้นเดียวในหัวข้อนี้ที่มีการแก้ไขโค้ดจากต้นฉบับหนังสือ)
- ตัวอย่างที่ 6: มีการเว้นวรรคซ้ำหลายตำแหน่ง เช่น `<span  style="color:blue;">` และ `<?php  echo $name;  ?>` ตามต้นฉบับหนังสือ จึงคงไว้ตามเดิม (จุดนี้เป็นเพียงความไม่สอดคล้องด้านรูปแบบ ไม่กระทบการทำงานของโปรแกรม จึงไม่แก้ไข)
- ตัวอย่างที่ 6: แท็ก `<span style="color: blue;" onclick="alert('...')...">` ถูกพิมพ์แยกเป็น 2 บรรทัดในหนังสือ (บรรทัดที่ 25 ตามเลขกำกับของหนังสือ) จึงคงการแยกบรรทัดไว้ตามเดิม
